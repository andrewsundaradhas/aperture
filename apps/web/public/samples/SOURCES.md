# Sample datasets

Real public robot data, cut down to a downloadable size by `scripts/build_samples.py`.

| File | Source | License |
|---|---|---|
| `xarm-lift-40-episodes.zip` | First 40 episodes of [`lerobot/xarm_lift_medium`](https://huggingface.co/datasets/lerobot/xarm_lift_medium), LeRobot v3 (policy rollouts, recorded in simulation) | MIT |
| `nyu-rot-xarm-real-robot.tfrecord` | `nyu_rot_dataset` from [Open X-Embodiment](https://robotics-transformer-x.github.io/) (real xArm robot) — Haldar et al., *Watch and Match: Supercharging Imitation with Regularized Optimal Transport*, CoRL 2022, https://rot-robot.github.io/ | CC BY 4.0 |
| `signal-logged-demo.tfrecord` | **Synthetic**, generated by `scripts/build_samples.py` from Aperture's own fixtures: RLDS episodes carrying action-confidence, contact-force and sub-goal channels, to demonstrate every failure cause | MIT (this repository) |
